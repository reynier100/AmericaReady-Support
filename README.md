# America Ready: Life Skills — Support

America Ready is a bilingual educational app for practicing everyday life skills in English and Spanish.

## Contact Support

Email: uscivicspractice@gmail.com

When contacting support, please include your iPhone model, iOS version, and a short description of the problem. Do not send passwords, financial information, medical records, or other sensitive personal information.

## Quick Help

- **No audio:** Check the audio setting inside the app, raise media volume, and tap the replay button.
- **Change language:** Open Settings and choose English or Spanish.
- **Reset progress:** Use the reset option in Settings only if you want to remove saved learning progress.
- **Daily reminder:** Notifications are optional and can be changed in iPhone Settings.
